# lean-work

Плагин для Claude Code: тот же результат (или лучше) при меньшем расходе лимитов.

Статус: v0.1, экономия ещё не измерена. См. `evals/tasks.md`.

## Что внутри

- `skills/efficient-work` — триаж задачи (шаг 0), маршрутизация по моделям, правила чистого контекста.
- `evals/tasks.md` — A/B-задачи для проверки: правило остаётся, только если качество не ниже и токенов меньше.

## Установка

```
/plugin marketplace add resccrew/lean-work
/plugin install lean-work@lean-work
```

Локально, без GitHub: `claude --plugin-dir <путь к этой папке>`.

## Принцип

Режем только мусор в контексте, не информацию, нужную для решения. Рискованные оптимизации по умолчанию выключены.
